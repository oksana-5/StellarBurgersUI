# StellarBurgersUI
## Автотесты для приложения космической бургерной Stellar Burgers.

### Проверяется:

#### Регистрация

Успешная регистрация;

Ошибка для некорректного пароля.

#### Вход

Вход по кнопке «Войти в аккаунт» на главной;

Вход через кнопку «Личный кабинет»;

Вход через кнопку в форме регистрации;

Вход через кнопку в форме восстановления пароля.

#### Раздел «Конструктор»

Работают переходы к разделам:

«Булки»;

«Соусы»;

«Начинки».

### В проекте используются:
JDK corretto-11, JInit 4.13.2,Selenium 4.35.0, Allure 2.15.0, Aspectj 1.9.7, Webdrivermanager 6.3.2, javafaker 1.0.2, gson 2.13.1, lombok 1.18.38, rest-assured 5.5.6 

#### Build system: 
maven
